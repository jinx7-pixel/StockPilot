Fixes are applied to the `main` branch and are picked up by anyone deploying
from it. Older snapshots are not patched.

## Reporting a vulnerability

**Please do not open a public issue for a security vulnerability.** Public
issues are visible immediately and are indexed by search engines within
minutes, which gives an attacker a head start.

Report it privately instead:

1. Go to **Security â†’ Report a vulnerability** on this repository:
   <https://github.com/jinx7-pixel/StockPilot/security/advisories/new>
2. Describe:
   - what the vulnerability is
   - the steps required to trigger it
   - the impact you believe it has
   - any proof-of-concept you have
3. You will get an acknowledgement within a few days.

If the private advisory form is not available to you, send the details to the
maintainer's email address in the repository README instead, and say in the
subject line that it is a private security report. Do not post the details in
a public issue while waiting for a reply.

### What to include

A good report contains the version or commit you tested, the exact steps to
reproduce, the observed and expected behaviour, and the impact on a real
deployment. A minimal proof of concept is more useful than a long description.

## Response timeline

This is a volunteer-maintained project, so treat these as targets rather than
commitments:

| Stage | Target |
| --- | --- |
| Acknowledgement | 3 days |
| Initial assessment | 7 days |
| Fix or mitigation plan | 14 days |
| Public advisory | After the fix ships |

If a report is not acknowledged within a week, that is a bug in this process

waiting on a security report, without including the details.

## What counts as a vulnerability

In scope:

- Authentication, authorisation, or session handling flaws
- Injection (SQL, command, template, XSS)
- Exposed secrets, credentials, or personal data
- Unsafe default configuration
- Denial of service that is trivial to trigger

Out of scope:

- Findings that require an already-compromised host
- Missing hardening headers with no demonstrated impact
- Self-inflicted denial of service
- Reports generated by an automated scanner with no working proof of concept

## Disclosure

Please give the maintainer a reasonable window to publish a fix before
disclosing publicly. Credit will be given in the advisory unless you prefer
otherwise.
